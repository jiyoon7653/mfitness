결론

Notion 하나로 다 하지 마세요

Notion은 대시보드와 누적 데이터에 강하고, 정산에는 결정적인 약점이 하나 있습니다. 그래서 운영은 Notion, 정산은 구글 스프레드시트로 나누는 하이브리드를 권합니다.

Notion으로 정산을 하면 안 되는 이유

Notion에는 행 단위 권한이 없습니다. 하나의 정산 DB에 모든 트레이너를 모으면, 그 DB를 볼 수 있는 사람은 남의 수업료·계약금액까지 전부 보게 됩니다. 트레이너별로 DB를 쪼개 페이지 권한을 나누면 서로 못 보게는 되지만, 이번엔 대표님이 볼 총수업료 자동 합산이 끊깁니다. 트레이너마다 별도 DB라 하나로 더할 방법이 없어서, 매달 대표님이 각 시트를 열어 총합을 손으로 옮겨 적어야 합니다.

구글 스프레드시트는 이 문제가 없습니다

권한이 파일 단위라, 트레이너별로 파일을 하나씩 만들고 각자 본인 파일만 공유하면 서로 볼 수 없습니다. 그리고 대표님 파일에서 IMPORTRANGE로 각 파일의 총수업료를 끌어오면 총합이 자동으로 계산됩니다. 트레이너는 본인 것만 보고, 대표님은 전부 보면서 합계까지 자동 — 요청하신 조건이 정확히 맞아떨어집니다.

다섯 개의 표, 그리고 그 안의 자동 계산

각 표에서 자동 표시된 칸은 직원이 입력하지 않습니다. 다른 칸에서 계산되거나 날짜에서 자동으로 나옵니다. 직원이 손대는 칸을 최대한 줄이는 것이 이 설계의 핵심입니다.

문자 발송은 법적으로 동의가 필요합니다

단순 문의로 받은 번호에 광고 문자를 보내려면 사전 수신동의가 있어야 하고, 문자 앞에 (광고), 끝에 무료 수신거부 번호를 넣어야 합니다. 오후 9시~오전 8시 발송은 별도 동의 없이는 금지입니다. 그래서 수신동의 · 발송제외 두 칸을 처음부터 넣었습니다. 상담 시 "할인 소식 문자로 보내드려도 될까요?" 한 마디를 습관화하시고, 동의한 건만 체크하시면 됩니다.

대표 승인 — 체크 한 번에 날짜가 박힙니다

선택하신 방식입니다. 수기 종이와 대조한 뒤 체크박스만 누르면 승인 시각과 승인자가 자동 기록되고, 그 뒤로는 트레이너가 그 달 시트를 수정할 수 없게 됩니다.

Google Apps Script · 도구 → 스크립트 편집기에 붙여넣기

function onEdit(e) {
  // 승인 체크박스(요약 시트 D2)가 켜지면 시각·승인자 기록
  const sh = e.range.getSheet();
  if (sh.getName() !== '요약') return;
  if (e.range.getA1Notation() !== 'D2') return;

  if (e.value === 'TRUE') {
    sh.getRange('E2').setValue(new Date());          // 승인일시
    sh.getRange('F2').setValue(Session.getActiveUser().getEmail());  // 승인자
  } else {
    sh.getRange('E2:F2').clearContent();             // 승인 취소 시 지움
  }
}

10줄짜리이고, 한 번 붙여넣으면 그 뒤로 손댈 일이 없습니다. 승인 취소도 체크 해제 한 번으로 되돌아갑니다.

서명의 법적 효력이 필요하시면

체크박스는 내부 확인 기록이지 법적 서명은 아닙니다. 지금처럼 수기 종이에 실제 서명을 하시고 그 종이를 보관하는 절차는 그대로 두시고, 이 체크박스는 "대조 끝났음"을 표시하는 용도로 쓰시는 걸 권합니다. 종이 서명본을 사진 찍어 해당 월 시트에 첨부해두면 나중에 찾기도 쉬워집니다.

예약 알림 메일 자동 파싱

예약이 들어오면 네이버가 보내는 알림 메일을 전용 지메일로 받고, Make나 Zapier가 그 메일에서 이름·일시를 뽑아 ②번 표에 카드를 자동 생성합니다.

  • 완전 자동 — 사람이 개입하지 않음
  • 단점: 알림 메일에 연락처가 안심번호로 가려져 올 수 있음 (실제 메일을 봐야 확인 가능)
  • 단점: 네이버가 메일 양식을 바꾸면 조용히 멈춤
  • 설정에 반나절, 월 유지비 발생 가능

사물함

헬스장 PC 프로그램은 제가 열 수 없습니다

먼저 분명히 말씀드립니다. 저는 대표님 헬스장 컴퓨터에 접근할 수 없고, 그 프로그램을 원격으로 열 수도 없습니다. 대신 그 프로그램에서 데이터를 꺼내오는 방법이 넷 있습니다 — 위에서부터 시도해보세요.

  1. 프로그램에 "엑셀 내보내기"가 있는지 확인

    회원 목록이나 사물함 화면에서 내보내기 · 엑셀 · 다운로드 버튼을 찾아보세요. 대부분의 국내 헬스장 프로그램에는 있습니다. 있으면 여기서 끝입니다 — 내보낸 파일을 구글 드라이브 동기화 폴더에 저장하면 Notion까지 자동으로 넘길 수 있습니다. 가장 먼저 확인해주실 항목입니다.

  2. 프로그램 회사에 데이터 제공을 문의

    "회원 데이터를 엑셀이나 API로 받고 싶다"고 고객센터에 문의하세요. 그 데이터는 대표님 소유입니다. 유료 옵션으로 제공하는 곳도 있고, 담당자가 직접 DB를 뽑아주는 경우도 있습니다.

  3. 내보내기가 없다면 — 윈도우 자동화(RPA)

    Power Automate Desktop은 윈도우 10·11에 기본 포함된 무료 도구입니다. "프로그램 실행 → 사물함 메뉴 클릭 → 화면 읽기 → 엑셀 저장"까지 사람이 하던 클릭을 그대로 녹화해 매일 자동 반복시킬 수 있습니다. 단, 이 자동화는 헬스장 PC에서만 돌아갑니다 — 그 PC가 켜져 있어야 합니다.

  4. 당장은 — 지금 엑셀을 그대로 옮기기

    직원분이 만든 엑셀을 ④번 표에 복사·붙여넣기 하면 끝입니다. Notion은 엑셀 붙여넣기를 표로 인식합니다. 그 다음부터는 만료 D-day와 추가결제 예상액이 자동으로 계산되고, "D-14 이내 미안내" 목록이 매일 아침 대시보드에 뜹니다. 주 1회만 갱신해도 지금보다 훨씬 낫습니다.

여기가 돈이 새는 지점입니다

12개월 헬스권에 6개월 사물함만 결제한 회원 한 명당, 월 사물함료가 1만원이면 6만원이 미수금입니다. 그런 회원이 30명이면 180만원입니다. 지금은 이 목록이 엑셀 파일 안에 잠들어 있어서 누가 열어보지 않으면 아무 일도 일어나지 않습니다. 4번 방법으로 하루 만에 옮겨두는 것만으로도 이번 달부터 회수가 시작됩니다.

문자 발송

모아둔 연락처를 실제로 쓰는 법

지금 바로 되는 방식

  1. ①번 표에서 조건으로 거릅니다 — 수신동의 O · 발송제외 X · 미등록 · 최근 3개월 유입
  2. Notion에서 CSV로 내보내기
  3. 알리고나 뿌리오 웹에 업로드해 발송
  4. 발송 결과를 ①번 표 메모에 기록

추가 개발 없이 오늘부터 가능합니다. 건당 문자 요금(대략 10~20원)만 듭니다.

자동 발송은 특히 조심하세요

사람이 한 번 훑고 보내는 것과 조건 맞으면 무조건 나가는 건 다릅니다. 이미 결제한 회원에게 독촉 문자가 나가거나 밤 10시에 발송되면 신뢰를 잃습니다. 자동으로 명단만 만들고 발송 버튼은 사람이 누르는 방식을 권합니다.

광고 문자 3원칙 — 위반 시 과태료 대상입니다

  • 사전 수신동의를 받은 번호에만 발송 (단순 문의 번호는 동의 아님)
  • 문자 맨 앞에 (광고), 맨 뒤에 무료 수신거부 번호 표기
  • 오후 9시 ~ 오전 8시 발송 금지 (별도 야간 수신동의가 있으면 예외)

3주에 나눠서

한 번에 다 켜면 직원들이 어느 것도 안 씁니다. 순서대로, 앞 단계가 습관이 된 뒤 다음을 붙입니다.

  1. 1주차 — 데스크가 쓰는 것부터

    ①연락처 · ②방문예약자 · ③체험PT 세 표와 대시보드를 만듭니다. 직원 교육은 10분이면 됩니다. 폰에 Notion 앱을 깔고 홈 화면에 바로가기를 걸어두는 것까지가 이 주의 일입니다. 이 주가 끝나면 "어제 몇 명 왔고 몇 명 등록했나"에 즉시 답할 수 있습니다.

  2. 2주차 — 정산

    트레이너 수만큼 구글 시트를 만들고, 총괄 시트에 IMPORTRANGE를 걸고, 승인 스크립트를 붙입니다. 이번 달 정산부터 바로 적용해보고 트레이너 피드백을 받습니다. 첫 달은 기존 종이 방식과 병행하며 숫자가 맞는지 대조하세요.

  3. 3주차 — 나머지와 자동화

    ④사물함 엑셀을 옮기고, ⑤목표·실적 표를 만들어 첫 주간보고를 이 시스템으로 돌려봅니다. 네이버 문진 링크와 문자 발송 흐름도 이때 붙입니다. 여기까지 오면 매주 취합에 쓰던 시간이 없어집니다.
