# M휘트니스 운영 허브

헬스장 운영 업무를 하나의 대시보드로 모으는 시스템입니다.

- `docs/gym-ops-hub.html` — 설계안 (브라우저로 열면 됩니다)

## 구축 상태

Notion에 구축 완료 (2026-08-29). 워크스페이스: M휘트니스용문점

| 항목 | 위치 |
|---|---|
| 대시보드 (오늘 할 일 · 예정된 업무 · 업무 성과) | Notion — 운영 허브 페이지 |
| ① 연락처 / ② 방문·예약자 / ③ 체험PT·OT / ④ 사물함 / ⑤ 목표·실적 | Notion 데이터베이스 |
| ⑥ 정산 | 구글 스프레드시트 (설정 안내는 Notion 하위 페이지) |

Notion 단독으로 가지 않는 이유는 행 단위 권한이 없어
트레이너 간 정산 비공개와 대표 총합 자동 합산을 동시에 만족할 수 없기 때문입니다.

## 자동 계산 항목

| 표 | 항목 | 계산 |
|---|---|---|
| ② | 방문 D-day / 방문 시점 | 방문 예정일 기준 |
| ③ | 진행 D-day / 진행 시점 | 진행일 기준 |
| ④ | 미결제 개월 | 헬스권 종료일 − 사물함 종료일 (개월) |
| ④ | 사물함 만료 D-day / 만료 임박도 | 사물함 종료일 기준 |
| ⑤ | 신규등록·체험PT·매출 달성률 | 달성 ÷ 목표 |
| ⑥ | 수업료 / 잔여 / 총수업료 | 구글 시트 수식 |

`시점`·`임박도` 열은 대시보드 필터 전용입니다.
Notion이 포뮬러 숫자 비교 필터를 지원하지 않아 구간 문자열로 계산합니다.
