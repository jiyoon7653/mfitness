# M휘트니스 운영 허브 — 설계안

헬스장 운영 업무를 하나의 대시보드로 모으기 위한 설계 문서입니다.
아직 구축 전 단계이며, 이 저장소에는 설계안 문서만 있습니다.

- `docs/gym-ops-hub.html` — 전체 설계안 (브라우저로 열면 됩니다)

## 요약

| 영역 | 도구 |
|---|---|
| 연락처 / 방문·예약자 / 체험PT·OT / 사물함 / 목표·실적 | Notion |
| 트레이너 정산 | 구글 스프레드시트 (권한 분리 + 자동 합산) |
| 대시보드 (오늘 할 일 · 예정된 업무 · 업무 성과) | Notion |

Notion 단독으로 가지 않는 이유는 행 단위 권한이 없어
트레이너 간 정산 비공개와 대표 총합 자동 합산을 동시에 만족할 수 없기 때문입니다.
자세한 내용은 설계안 문서를 참고하세요.
